# Переклад кампаній HoMM4 українською

## Що є
- `catalog/Campaign.<Name>_Campaign.json` — рядки кампанії, які бачить гравець: `{"id", "where", "en", "uk"}`. Перекладати = заповнювати `uk`. Порожнє `uk` — рядок лишається англійським.
- `GLOSSARY.md` — імена, назви, терміни, правила стилю. Обов'язковий для всіх кампаній. Нові імена/назви дописувати в нього (лише додавати рядки, не переписувати чужі).
- `tools/apply.py <game dir>` — збирає кампанії з каталогів і латає архіви гри (робить лише одна сесія, що відповідає за збірку).

## Як перекладати
1. Читати каталог шматками по 10–20 рядків (`python3 -I -c` з `json.load`), перекладати й записувати `uk` у той самий файл маленьким Python-скриптом після кожного шматка, щоб не втратити роботу.
2. Однакові `en` в одному файлі — однаковий `uk`.
3. Зберігати структуру: абзаци (`\n\n`), перенесення (`\n`), лапки в діалогах (`"` → «»), кінцеві `\n`, якщо вони є в оригіналі.
4. Не перекладати службові мітки редактора (Event N, Timed Event, Starting/Opening Text, Follow Up, Day N event) — лишати `uk` порожнім.
5. Кодування: текст піде у Windows-1251. Лише українські літери, латиниця, цифри, «» „“ — … ’ №. Без емодзі та інших символів.
6. Не змінювати `en`, `id`, `where`; не додавати й не видаляти записи.
7. Перевірка в кінці: `python3 -I -c "import json; d=json.load(open('<файл>')); print(sum(1 for i in d if i['uk']), len(d))"` і що кожен `uk` кодується в cp1251.
